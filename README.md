# UCP agent profile

在庫の確認だけを行うツールが、Shopify の店の公式の窓口（UCP）に問い合わせるときに名乗るための書類です。カート・注文・支払いの操作は行いません。

This profile identifies a read-only stock-check tool (catalog lookup only) when it calls a Shopify store's UCP endpoint. It does not create carts, checkouts, or orders.

- Profile: `stock-monitor.json`
